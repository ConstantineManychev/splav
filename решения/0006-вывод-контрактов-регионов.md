# 0006. Контракт регионов выводится из тела

- Статус: принято; дополнено записью 0050
- Версия: v0.050
- Спецификация: §4.1, п. 8; §13, строка «Вывод контрактов регионов»; §14.1

## Решение

Сигнатура пишется без меток регионов. Контракт — какие регионы должны пережить какие — компилятор выводит из тела и проверяет в каждом вызове.

## Причина

Умолчания сигнатур первой записи правил отвергали корпус: `разборщик.значение()` требовал, чтобы локальный `разборщик` жил в арене контекста. Это нашёл прототип проверки на разборе JSON (§14.1).

## Отвергнутые варианты

- Умолчания по сигнатуре для функций с телом: остались только там, где тела нет, — `внеш`, `[Встроено]`, сигнатуры типажа.
- Обязательные метки регионов в сигнатурах: это времена жизни в интерфейсе (запись 0002).

## Плата

§13: изменение тела `откр`-функции меняет её контракт.
