# 0050. Контракты `откр`-функций записаны в `пакет.контракты`

- Статус: принято
- Версия: v0.180
- Спецификация: §4.1, п. 8; С0701; §13, строка «Вывод контрактов регионов»
- Дополняет: запись 0006

## Решение

`сплав` записывает контракты регионов `откр`-функций вместе с `требует` и признаком приостановки в файл `пакет.контракты` рядом с манифестом. Сборка сверяет выведенные контракты с записанными и при расхождении останавливается с ошибкой С0701 и разницей; `сплав контракты` переписывает файл. Ослабление контракта совместимо, усиление — несовместимое изменение версии пакета; метки в сигнатуре задают контракт явно.

## Причина

Правка тела `откр`-функции молча меняла API пакета. Теперь изменение контракта — явная правка файла в той же фиксации, её видно на ревью, а сигнатуры по-прежнему без меток.

## Отвергнутые варианты

- Обязательные метки в сигнатурах `откр`-функций: шум в типичном случае, где контракт очевиден.
- Сравнение с прошлой версией пакета только при выпуске — прежнее смягчение: ловит поздно.
- Записывать контракты комментариями в исходнике: комментарии не проверяются.

## Плата

Ещё один файл в пакете и его правка при каждом изменении контракта.
