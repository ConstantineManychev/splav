# 0026. Закреплён выпуск LLVM/MLIR 23.1.5

- Статус: принято
- Версия: v0.050.13
- Спецификация: §14.2, п. 4; §14.4; `cmake/llvm.cmake`

## Решение

Компилятор собирается с LLVM/MLIR ровно 23.1.5 — выпуск от 3 ноября 2026 года: CMake сверяет версию точно. CI берёт официальный архив выпуска и сверяет его sha256. FileCheck в архив не входит, поэтому собирается из исходника того же тега и линкуется с `libLLVMFileCheck` из архива. Переход на новый выпуск — отдельная запись.

## Причина

C++ API MLIR меняется между выпусками (§14.2, п. 4): без закрепления сборка ломается сама.

## Отвергнутые варианты

- LLVM из пакетов системы: на каждой ОС своя версия, в образе Ubuntu 24.04 — 18.
- Сборка LLVM из исходников в CI: часы на прогон ради того же результата.
- Диапазон версий или ветка `main` LLVM: см. причину.
