# 0043. CI: три ОС, санитайзеры, фаззинг; MLIR — по изменениям и раз в неделю

- Статус: принято
- Версия: v0.050.13
- Спецификация: §14.2, п. 5; `.github/workflows/`

## Решение

На каждый коммит: проверки на Python и сборка с тестами на Linux, Windows и macOS, ASan и UBSan, две минуты libFuzzer, проверка стиля. Сборка диалекта с LLVM — только при изменениях в `компилятор/dialect/` и `cmake/` и раз в неделю, архив LLVM — из кэша. В Linux импорт заголовков обязан идти через libclang: откат на снимки роняет проверку.

## Причина

Архив LLVM занимает гигабайты: качать его на каждый коммит незачем, а недельный прогон ловит поломку окружения. Откат на снимки скрыл бы, что `вставка` перестала читать настоящие заголовки.

## Отвергнутые варианты

- Сборка диалекта на каждый коммит.
- Закрепление версии LLVM без сборки: оно ничего не проверяет.

## Плата

В Windows откат на снимок `zlib.h` ожидаем: zlib там нет.
