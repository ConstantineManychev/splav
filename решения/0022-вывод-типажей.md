# 0022. Четыре типажа выводятся по строению типа, но только по строке `реализ`

- Статус: принято
- Версия: v0.050.12
- Спецификация: §12.3; §3.7, п. 8

## Решение

`Равенство`, `Сравнение`, `Хеширование` и `Показ` компилятор выводит по полям и вариантам, если тип объявил `реализ Типаж для Тип` без своего метода. Вывод требует того же типажа у каждого поля.

## Причина

Ничего неявного: без строки `реализ` у своего типа нет ни `==`, ни печати. Правило сразу нашло пропуск в ядре — `ос.ОшибкаВвода` печаталась без `реализ Показ`.

## Отвергнутые варианты

- `==` и печать у любого типа без объявления: неявное поведение (§1, п. 1). *(восстановлено по смыслу: в спецификации не записано)*
- Вывод макросом или атрибутом: макросов в языке нет (§12.5, п. 7). *(восстановлено по смыслу: в спецификации не записано)*
