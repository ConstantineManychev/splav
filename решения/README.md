# Журнал решений

Каждое решение языка и компилятора — отдельная запись: что решено, почему, какие варианты отвергнуты, в какой версии и где это правило в спецификации (§14.2, п. 5).

- Нормативна спецификация «Сплав — спецификация языка». Запись не пересказывает правило, а ссылается на раздел: если запись и спецификация расходятся, права спецификация, а запись исправляют.
- Принятую запись не переписывают. Новое решение получает новую запись со следующим номером, а прежняя — статус «заменено записью NNNN» или, если новое решение её расширяет, «дополнено записью NNNN».
- Версия — выпуск спецификации, в котором решение принято. У решений старше журнала стоит «до журнала»: они приняты не позже v0.050.12, а точной версии в спецификации нет.
- Отвергнутый вариант с пометкой «восстановлено по смыслу» спецификация прямо не называет: он записан по её тексту при заведении журнала в v0.050.13 и ждёт проверки автором языка.
- Файл записи — `NNNN-имя.md` с разделами «Решение», «Причина», «Отвергнутые варианты» и, если у решения есть цена, «Плата».
