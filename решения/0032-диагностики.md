# 0032. Диагностики: по-русски, со стабильными кодами, JSON и SARIF

- Статус: принято
- Версия: до заведения журнала, не позже v0.050.12; точная версия в спецификации не записана. Диапазоны кодов — v0.050.12, коды С0101–С0117, С0201–С0211 и С0302–С0315 — v0.050.13
- Спецификация: §11.2; §11.4

## Решение

Диагностики по умолчанию на русском, `--язык=en` — на английском. У каждой — стабильный код вида `С0412`; `сплав объяснить` печатает статью. Машинный вывод — JSON для LSP и SARIF для CI.

## Причина

Код не зависит от языка сообщения: по нему ищут статью, пишут тесты и фильтруют вывод в CI.
