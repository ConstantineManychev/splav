# 0058. Номер версии по готовности: v0.180; имя документа без версии

- Статус: принято
- Версия: v0.180
- Спецификация: §14

## Решение

Номер версии — оценка пути до 1.0: v0.180 — около 18 %, мелкие правки получают суффикс через точку. Номера до v0.050.13 шли по прежней, заниженной оценке. Имя живого документа и его файла в репозитории версии не содержат: она стоит в заголовке.

## Причина

Решение автора языка в v0.180. Прежний номер занижал готовность, а версия в имени файла заставляла каждый выпуск удалять файл и добавлять новый.

## Отвергнутые варианты

- Семантическое версионирование до 1.0: номер не говорил бы о готовности. *(восстановлено по смыслу)*
