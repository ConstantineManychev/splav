# 0052. Раздувание кода от `компил`: ICF и нешаблонное ядро контейнеров

- Статус: принято
- Версия: v0.180
- Спецификация: §11; §12.5, п. 6; §13, строка «Обобщения через `компил`»
- Дополняет: запись 0008

## Решение

LLVM и компоновщик схлопывают одинаковый машинный код разных инстанцирований (ICF). Контейнеры `ядро` — тонкая типобезопасная обёртка на `компил` над нешаблонным ядром по указателю, размеру и выравниванию. Адреса функций не уникальны и, как прочие адреса, вне гарантии §3.7; отладочная сборка функции не схлопывает.

## Причина

Решение автора языка в v0.180. Раздувание снимается кодогенерацией без изменения семантики языка.

## Отвергнутые варианты

- Стирание типов по умолчанию: потеря скорости на каждом вызове. *(восстановлено по смыслу)*
- `дин` везде, где растёт код: ручная работа автора программы. *(восстановлено по смыслу)*

## Плата

Разные функции могут иметь один адрес; разный машинный код по-прежнему растёт с каждым набором типов.
