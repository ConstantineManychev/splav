# 0013. Импорт C без биндингов: `вставка` через Clang

- Статус: принято; дополнено записью 0057
- Версия: до заведения журнала, не позже v0.050.12; точная версия в спецификации не записана. Правила уточнила утилита сжатия в v0.050.11 (§14.1)
- Спецификация: §8; §11.2, поле `си`; §13, строка «Импорт C без биндингов»

## Решение

`вставка "файл.h"` — не текстовое включение: Clang внутри компилятора разбирает заголовок под цель, и он становится модулем. Точные типы задаёт ручное объявление `внеш`.

## Причина

Объявления не расходятся с заголовком, а платформозависимые типы получают ширину цели, а не хоста (§8, п. 3; §11.2).

## Отвергнутые варианты

- Текстовое `#include` (§8, п. 2).
- Только ручные объявления `внеш`: остались для точных типов вроде `[*:0]н8`, которых из заголовка не узнать (§8, п. 5).

## Плата

§13: сложные функциональные макросы недоступны; безопасность C-вызова — доверие.
