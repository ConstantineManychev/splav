# 0010. `набор`: структура массивов и прокси-ссылки

- Статус: принято; дополнено записью 0057
- Версия: до заведения журнала, не позже v0.050.12; точная версия в спецификации не записана. Прокси тремя параметрами — v0.050.7, клон по диапазону и сдвиг колонок — v0.050.8 (§14.1)
- Спецификация: §1, п. 3; §5; §11; §13, строка «SoA и указатели»

## Решение

`набор` хранит коллекции как структуру массивов. Ссылка на элемент — прокси из базы, ёмкости и индекса; фронтенд передаёт его тремя скалярными параметрами. Массив структур — только явной сборкой `собратьAoS`.

## Причина

Раскладка — часть типа (§1, п. 3): цикл читает только нужные колонки и векторизуется, а на ГПУ пересылаются только они (§5, п. 2 и 8).

## Отвергнутые варианты

- Прокси структурой в 24 байта: на всех целевых ABI шёл бы через память (§5, п. 4; §11).
- Неявное копирование в массив структур для C и сериализации (§5, п. 6).
- Вызов невстроенной функции на каждый элемент: в 4,5–8,4 раза медленнее встроенного цикла, поэтому цикл заменяется клоном по диапазону (§5, п. 4).
